# ADR 0001: Name the project Craftgate

**Date:** 2026-11-11 · **Status:** Accepted

## Context

The working name "Atelier" collides with several Claude-ecosystem tools, including martinffx/claude-code-atelier, heyman333/atelier-ui (a Claude Code UI-design marketplace) and rachidchabane/atelier. "Hallmark" and "Craft" are also taken.

## Decision

Use **Craftgate**. Light searches found no collision, and the name describes the product: a gate on front-end craft before merge. The benchmark is called **CraftBench** inside the project.

## Alternatives rejected

- Atelier — direct ecosystem collisions
- Loupe — existing non-Claude dev tools
- Atelier + CraftBench — keeps the collision

## Consequences

Confirm on npm and trademark registers before the first public release.
